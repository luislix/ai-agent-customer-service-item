# 选品模块

## 作用与边界

`src/modules/sourcing/` 从货源平台搜索商品，统一计算销售渠道的售价、佣金、物流和利润，按规则生成每日选品清单。选品结果必须人工审核后才能进入推广或商品知识流程；模块不负责客服回复和公开发布。

## 输入、依赖与数据

- 输入：关键词、平台配置和可选的 Onebound/justoneapi 凭证。
- 依赖：`SOURCING_PROVIDER` 选择数据源；无凭证时使用离线样例，仅用于验证流程。
- 数据：选品清单、商品快照和审核状态写入 `DB_PATH` 指向的 SQLite。

## 使用流程

```bash
python -m scripts.run_sourcing_demo 手机支架
python -m scripts.run_daily_sourcing
```

运行常驻调度：

```bash
python -m scripts.run_scheduler
```

默认 `09:00` 执行每日选品。控制台中将结果标记为 `approved` 后，推广任务才会消费该快照。配置和默认值见 [`../配置说明.md`](../配置说明.md)。

## 关键规则

- 规则评分可复现，但离线样例不代表真实货源质量。
- 商品主图、价格、事实卖点和来源链接保存为快照，内容生成不重新依赖供应商接口。
- 审核拒绝或缺少必要商品事实的结果不得进入推广和 RAG。

## 关键入口与排障

- `src/modules/sourcing/agent.py`：搜索、渠道比较和商品转换。
- `src/modules/sourcing/platforms.py`：佣金、物流和利润模型。
- `src/modules/sourcing/daily_job.py`：每日任务。
- `src/modules/sourcing/store.py`：SQLite 持久化。

无结果时先用 `run_sourcing_demo` 排除代码问题，再检查 token、关键词、provider 和网络连通性。
