# 商品快照采集器

商品采集器是 `xianyu_product_crawler/` 下的独立模块，负责从授权 API、fixture 或明确允许的页面流程生成 JSONL 快照和审阅报告。它不读取当前项目的 RAG 数据库，也不自动导入生产知识库。

## 使用入口

完整安装、Chrome 扩展、手动采集和 CLI 参数见 [`../../xianyu_product_crawler/README.md`](../../xianyu_product_crawler/README.md)。典型离线运行：

```bash
cd xianyu_product_crawler
PYTHONPATH=src python -m xianyu_product_crawler \
  --keyword-file keywords.txt --fixture fixtures/provider.json \
  --output out/product_snapshots.jsonl \
  --markdown out/review.md --errors out/errors.jsonl
```

## 边界与交接

人工审核 `out/review.md` 后，回到项目根目录按 [`商品RAG模块手册.md`](商品RAG模块手册.md) 的流程校验和导入。登录失效、验证码或安全验证时停止任务，不尝试绕过平台控制。
