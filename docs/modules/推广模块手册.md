# 推广模块

## 作用与边界

`src/modules/promotion/` 将已审核选品转换为小红书图文发布包和微信服务号草稿，生成卡片、正文和审计 manifest，并记录渠道交付状态。最终公开发帖和微信公开发布不由模块自动执行。

## 输入、依赖与数据

- 输入：前一天已审核的国内选品快照。
- 依赖：LLM（无凭证时模板降级）、Chrome/Edge 卡片渲染、小红书浏览器 profile、可选微信服务号凭证。
- 数据：内容任务和渠道交付状态写入 SQLite；发布包位于 `data/promotion/<date>/<id>/`。

## 使用流程

```bash
python -m scripts.run_daily_xhs
python -m scripts.run_daily_promotion
```

控制台审核内容后，可执行小红书自动填充：

```bash
python -m scripts.prepare_xhs_browser --content-id <已审核内容ID>
```

浏览器会上传 `cover.png`、`content.png` 并填写标题正文，停在最终发布前；运营检查后手动发布，再回控制台标记已发布。微信首期只创建草稿。

## 状态与幂等

```text
pending_review -> approved
                         ├─ wechat: pending -> draft_created / failed
                         └─ xhs: package_ready -> awaiting_manual_publish -> published
```

同一日期/选品和同一内容/渠道具有唯一约束，重复调度不会重复生成。

## 关键入口与排障

- `src/modules/promotion/daily_job.py`：每日内容任务。
- `src/modules/promotion/xhs_exporter.py`：发布包输出。
- `src/modules/promotion/xhs_browser.py`：浏览器自动填充。
- `src/modules/promotion/publishing.py`：审批后的渠道交付。

卡片渲染失败时检查 Chrome/Edge 或 `CHROME_PATH`；小红书失败时检查 Node、`npx`、登录 profile 和页面状态，遇到验证码或风控停止自动化并使用发布包人工操作。
