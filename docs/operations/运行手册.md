# 运行与验证手册

本文只描述项目级的安装、体检、调度、控制台和通用排障。模块专属操作见 [`../modules/`](../modules/)。涉及未实现的实时 Provider、自动公开发布或生产后台，请查看 [`../plans/商品RAG改造实施计划.md`](../plans/商品RAG改造实施计划.md) 和归档资料。

## 前置条件

- Python 3.10 或更高版本。
- 离线验证需要 Python 标准库和 `pytest`；真实接入、LLM 和 RAG 依赖见 `requirements.txt`。
- 推广卡片渲染需要 Chrome 或 Edge，可用 `CHROME_PATH` 指定路径。
- 闲鱼实时私信需要单独准备 `XianYuApis` 和 Node.js 18+。

## 安装和体检

```bash
python -m venv .venv
source .venv/bin/activate              # Windows: .venv\Scripts\activate
python -m pip install pytest
# 需要真实平台、LLM 或 RAG 时再安装：
# python -m pip install -r requirements.txt
cp .env.example .env
python -m pytest -q
python -m scripts.run_phase0_check
```

凭证为空时，体检报告中的 `SKIPPED` 是预期结果；`FAILED` 才表示已配置的外部接口异常。

## 控制台和调度

启动运营控制台：

```bash
python -m scripts.run_console
```

访问 `http://127.0.0.1:8000`。控制台用于审核选品、审核推广内容、处理工单和维护商品知识草稿。

常驻每日调度：

```bash
python -m scripts.run_scheduler
```

默认 `09:00` 执行选品，`10:00` 使用前一天已审核的国内选品生成推广内容。调度状态写入 SQLite，进程重启不会重复执行当天任务。单独任务和模块专属参数见：

- [`modules/选品模块手册.md`](../modules/选品模块手册.md)
- [`modules/推广模块手册.md`](../modules/推广模块手册.md)
- [`modules/客服模块手册.md`](../modules/客服模块手册.md)
- [`modules/商品RAG模块手册.md`](../modules/商品RAG模块手册.md)
- [`modules/商品快照采集器手册.md`](../modules/商品快照采集器手册.md)

## 通用排障

| 现象 | 处理 |
|---|---|
| 全部模块为 `SKIPPED` | 复制 `.env.example` 为 `.env`，按模块补齐凭证后重跑体检。 |
| 控制台没有数据 | 确认脚本和控制台使用同一个 `DB_PATH`，再检查任务是否成功写入 SQLite。 |
| 卡片渲染失败 | 确认 Chrome/Edge 可执行文件，或在 `.env` 设置 `CHROME_PATH`。 |
| 模块变成 `MANUAL` | 查看控制台工单原因，处理凭证、网络、限流或页面风控后，再人工恢复模块。 |
| 闲鱼触发验证码或风控 | 停止重试，按 [`闲鱼安全测试清单.md`](闲鱼安全测试清单.md) 冷却并转人工。 |
| RAG 导入失败 | 先运行模块手册中的 `--validate-only`，根据错误行检查时间、URL、金额和 `item_id`。 |

## 运行产物

主要产物包括：

```text
data/app.db                         # 选品、推广、工单和调度状态
data/promotion/<date>/<id>/         # 推广图片、正文和 manifest
xianyu_product_crawler/out/        # 采集器输出
.xhs-browser-profile/              # 本地浏览器登录态
```

这些目录已加入 `.gitignore`。不要提交凭证、浏览器 profile、数据库、真实商品快照或平台登录态。
